# 《千古一局：暗合推演》游戏概念文档（Game Concept Document v3.0）

## 1. 项目概述与参考标杆

* **一句话高概念**：一款以历史或经典原著战役为舞台的**异步多智能体悬疑博弈与暗合推演平台**。在人物性格与时代认知完全锁定的铁律下，多阵营玩家（涵盖主帅、谋士与基层小人物）通过“盲盒身份附身排错、信息差投喂、短期念头微调与支线固化”，在云端夜间深度推演中揪出敌方篡改黑手、构造“无论对手怎么选都会落入算计”的羊毛闭环局，并借助 2.5D 动态战略沙盘复盘因果链、争夺角色榜单与终局历史切片公演资格。

* **核心参考标杆与灵感来源**：

  * **《我的玩家都是演技派》（作者：青衫取醉，[起点中文网详情页](https://www.qidian.com/book/1033210790/)）**：深度借鉴其游戏内核心玩法《暗沙（归序者笔记）》的四大悬疑推演机制——**消耗身份点数换卡附身与排除原生怂货 NPC**（[第64章《还真是个贪生怕死之徒啊！》](https://ixdzs8.com/read/377684/p64.html)）、**OOC 违和度警觉防莽夫**（[第64章](https://ixdzs8.com/read/377684/p64.html)）、**跨轮次身份纠正与支线固化**（[第64章](https://ixdzs8.com/read/377684/p64.html)），以及**试炼幻境刷榜选拔 Top 玩家进入 100% 拟真终极历史切片公演**（[第43章《全新玩法开启！》](https://ixdzs8.com/read/377684/p43.html)、[第65章《孟原的任务》](https://ixdzs8.com/read/377684/p65.html)、[第79章《归序者的远征！》](https://ixdzs8.com/read/377684/p79.html)）。

  * **《这游戏也太真实了》（作者：晨星LL，[起点中文网详情页](https://www.qidian.com/book/1029391348/)）**：深度借鉴其“第四天灾”玩家群体分段式情报众包、精英玩家（如俱乐部管理员[来日方长](https://ubook.reader.qq.com/char-baike/3dyr9wrwzw8ww)）局部战术推演与战役尾声全局改写（[第412章《战役的尾声》](https://weread.qq.com/web/reader/aa832a7072591074aa8dc89k41a32fb031a141ae36eca30)），以及“宏观主线缓慢推进 + 局部高潮快反馈切片”的双层叙事节奏（[《这游戏也太真实了》节奏与机制分析](https://maliangwriter.com/library/%E8%BF%99%E6%B8%B8%E6%88%8F%E4%B9%9F%E5%A4%AA%E7%9C%9F%E5%AE%9E%E4%BA%86-24fec50c/)）。

* **目标体验**：

  1. **悬疑排错的刑侦快感**：不知道敌方玩家究竟篡改/附身了哪几个小人物，必须靠换卡试探、跟踪观察，区分“原生贪生怕死的烟雾弹 NPC”与“真正带任务的敌方暗棋”。

  2. **飙戏潜伏的紧张感**：附身敌营或敏感角色时，一言一行受“OOC 违和度警觉条”约束，一旦莽撞试探立刻触发主帅疑心或影侍灭口。

  3. **滚雪球固化的养成爽感**：每一次成功的局部排错与合理扮演都会“固化”为我方 AI 的自动支线，玩家得以腾出身份点数去撬动更核心的死局。

  4. **高烈度军师智斗与 2.5D 群像史诗**：以小博大构造反事实死局（羊毛局），并在 2.5D 沙盘时间轴上观赏全员因果碰撞。

* **节奏定位（双轨三阶结构）**：

  * **日间试炼幻境（Daytime Trial Illusion，单人/小队 3–5 秒快推副本）**：低算力消耗的局部平行幻境，供玩家消耗身份点数试错、排雷、刷角色契合度与还原度榜单（对应[《我的玩家都是演技派》第65章](https://ixdzs8.com/read/377684/p65.html)的“试炼幻境”）。

  * **夜间主线异步战役（Nightly Campaign，5 天一局）**：每日各角色榜单 Top 1 玩家的“已固化支线 + 暗棋指令”进入夜间云端 BSP 队列合龙碰撞，次日清晨生成 2.5D 沙盘回放；劣势方支持从 PostgreSQL JSONB 历史分叉点（Fork Timeline）读档重开。

  * **单夜残局与终局远征模式（Live Finale Slice）**：聚焦“草船借箭当夜”或“赤壁火攻决战夜”的终极历史切片公演（对应[《我的玩家都是演技派》第79章](https://ixdzs8.com/read/377684/p79.html)的“归序者远征”）。

## 2. 四大设计支柱（Design Pillars v3.0）

1. **时代铁律绝对约束（Era Plausibility First）**
   严禁出现超越时代背景的武器、科技（如黑火药配方）、现代博弈论术语或“上帝视角”全知情报。通过“结构化指令槽位 + Unicode NFKC 反混淆与时代词库白名单 + 史官转译器”三道防线物理隔离玩家输入，确保一切博弈在建安十三年（208 AD）的生产力与认知边界内运行。

2. **逻辑归代码，演技归 AI（Immutable Core & State Machine）**
   历史人物的性格、智力、价值观与人际关系全部锁死，关键心理阈值（`0–100`）、单向棘轮（`>= 70` 锁死执念）与事实锚点（`FactAnchor`）由服务端确定性代码状态机控制。AI 智能体只负责在约束下演绎对话与情绪反应，彻底杜绝 AI 半路“圣母心软”或“逻辑吃书”。

3. **盲盒潜伏 × 演技排错 × 支线固化（Blind-Box Deduction & Branch Solidification）**
   彻底告别“开局明牌知道对手是谁”的传统棋类视角。战局中 25–30+ 角色谁被敌方篡改、谁是原生怂货全处于迷雾中；玩家依靠【记忆碎片】接触解锁新身份卡、在 OOC 违和度红线内飙戏试探、排除错误答案，并将验证成功的行为固化为下一轮的确定性盟友支线（源自[《我的玩家都是演技派》第64章](https://ixdzs8.com/read/377684/p64.html)）。

4. **明线史诗 × 暗线猜招 × 沙盘演出（Visible Epic, Hidden Moves）**
   历史名场面不是固定播片，而是多阵营暗棋与固化支线碰撞的涌现结果。所有推演通过“五类零穿帮动作原语（`MOVE` / `INTERACT` / `EMOTE` / `VFX` / `ANCHOR_LOCK`）”驱动 2.5D 地图人物走位、密谈与立绘演出。

## 3. 核心循环与“试炼幻境 → 终局切片”双层推进流程

### 3.1 核心循环（Core Loop v3.0）

**观看昨日 2.5D 沙盘战报与物理表象线索 → 进入日间【试炼幻境】消耗身份点数换卡附身排错 → 在 OOC 违和度阈值内试探可疑 NPC 并触发【记忆碎片】解锁关键卡 → 将正确破局路径【支线固化】并冲击单角色榜 Top 1 → 夜间云端 BSP 队列汇总各角色 Top 1 方案做深度碰撞与反事实死局验算 → 次日生成 2.5D 演出时间轴（Day 5 开启终局历史切片公演）**

### 3.2 双层异步推进时间轴

| 阶段 | 执行主体 | 核心动作 | 输出产物 | 
| ----- | ----- | ----- | ----- | 
| **1. 沙盘复盘与线索认领** | 玩家（客户端） | 在 2.5D 沙盘时间轴回看昨日异常事件（如粮草迟滞、密信外泄），从公开/半公开线索池领取调查切入点 | 锁定今日怀疑的目标舞台与嫌疑人范围 | 
| **2. 试炼幻境换卡排错** | 玩家（日间快通道） | 消耗身份点数（Identity Points）附身基层角色跑 3–5 秒局部试算；验证某 NPC 是“原生性格缺陷”还是“敌方篡改内鬼” | 排除错误干扰项、通过【记忆碎片】解锁高阶角色卡 |

## 4. 四大升级核心机制（融合《演技派》与《太真实》）

### 4.1 机制一：盲盒内鬼排错与“原生烟雾弹 NPC”（Blind-Box Mole Hunting）

参考[《我的玩家都是演技派》第64章](https://ixdzs8.com/read/377684/p64.html)中楚歌连续三次附身文弱书生汪景辉被杀、后换卡附身武生杨信岩跟踪才发现汪景辉并非妖魔篡改而是“真贪生怕死想逃跑”的设计，游戏将多阵营博弈升级为“捉鬼 + 下棋”双层迷雾：

* **篡改迷雾（Tamper Fog）**：
  每局赤壁战役的 25–30 名角色中，敌方玩家（或系统演武场的“乱序黑手”）仅秘密附身/篡改了其中 **2–3 个关键节点角色**（例如曹营的乌林粮草官、传令小校，或江东的主战派老水手）。所有玩家均不知道敌方真人到底附身在谁身上。

* **原生烟雾弹 NPC（Native Red-Herring Cowards/Greed）**：
  角色库（`CHIBI_PERSONA_CATALOG`）中专门配置一批**自带原生人性弱点的非篡改 NPC**（如怕死逃跑的书佐、贪墨军粮推诿的军需官、因私怨压下军报的校尉）。他们在沙盘上同样会表现出“鬼祟夜行、延误军机、账目不符”等异常表象，形成天然的侦察干扰项。

* **【记忆碎片】接触式解锁（Memory Fragment Unlocking）**：
  玩家开局仅持有 1–2 张基础边缘身份卡（如巡夜兵丁、水寨杂役，对应 `1 点身份点数`）。只有控制当前角色在沙盘同一舞台槽位（`Slot`）与目标人物发生近距离交互、跟踪或截获信物（如截获城防图/水军布防图，见[《演技派》第65章](https://ixdzs8.com/read/377684/p65.html)），才能触发【记忆碎片】解锁蒋干、蔡瑁、鲁肃等中高层角色卡的附身权限，杜绝开局无脑抢大将。

### 4.2 机制二：OOC 违和度警觉条与“潜伏飙戏法则”（OOC Suspicion & Acting Check）

参考[《我的玩家都是演技派》第64章](https://ixdzs8.com/read/377684/p64.html)中楚歌附身平时胆小怕事的杨信岩后，因顾忌人设而不敢贸然找名角苏羡君盘问的约束，在确定性状态机（`state_machine.py`）中新增针对玩家自身的**违和度警觉槽（`ooc_suspicion: 0–100`）**：

* **人设行为包络线（Persona Behavior Envelope）**：
  每个角色除了锁死核心性格外，还定义了**对外言行边界**（例如：胆小书佐绝不会主动向曹操拍胸脯献计；粗豪水手绝不会引经据典谈兵法；江东主和派文官绝不会无故深夜独闯水寨）。

* **三级违和度惩罚阶梯**：

  1. **轻度违和（`ooc_suspicion 40–69`，言行略出格）**：周围同舞台 AI 角色产生警觉（触发 `EMOTE_SUSPICION`），对该角色的信任度下降，套话成功率减半，不再向其透露私密情报（`PrivateHorizonContext` 收窄）。

  2. **重度违和（`ooc_suspicion 70–89`，强行莽撞试探/越级行事）**：触发单向警觉棘轮，直接向阵营主帅或执法官冒泡上报 `EVENT_ABNORMAL_SUBORDINATE`，该角色被停职软禁，丧失本回合后续行动窗口。

  3. **致命暴露（`ooc_suspicion >= 90`，完全背离人设或露出马脚）**：直接触发敌方刺客/影侍（如曹营校事府、江东暗探）深夜灭口或军法处斩（类似[《演技派》第64章](https://ixdzs8.com/read/377684/p64.html)屋顶东夷影侍瞬杀），玩家本轮投入在该角色身上的身份点数与蝴蝶点数全额作废。

### 4.3 机制三：跨轮次“身份纠正与支线固化”（Identity Correction & Branch Solidification）

参考[《我的玩家都是演技派》第64章](https://ixdzs8.com/read/377684/p64.html)的核心减负机制——“当玩家附身一个被篡改的角色，并按照该角色原本应有的历史逻辑做出正确应对后，该角色即被纠正并固化，下一轮玩家换卡附身别人时，已被固化的角色会自动沿着纠正后的轨道运行”：

* **为什么必须引入支线固化**：
  在 25–30 人的赤壁大沙盘中，如果真人玩家每回合只有 3 点身份点数，却要同时堵住“蒋干盗书、粮道潜入、水寨流言”三个漏洞，玩家必然陷入分身乏术的微操地狱。

* **支线固化三步走（Solidification Loop）**：

  1. **排错与纠偏**：玩家在日间试炼或前序回合附身某关键小人物（如 `char_wulin_granary` 乌林粮草官），在不触发 OOC 警觉的前提下，识破敌方投喂的假军报并完成合规纠偏（如按规制双印核验、向程昱秘报）。

  2. **判定固化（Solidify Lock）**：服务端判定该角色的 `persona_fit_score >= 85` 且成功解除篡改危机后，将该角色本阶段的修正行为写入分支快照的 `solidified_branches` 只读表。

  3. **换卡滚雪球（Snowball Handoff）**：下一轮（或下一次试炼重开）中，玩家无需再消耗身份点数附身该粮草官，AI 会 100% 自动复现已固化的“双印核验+秘报程昱”支线；玩家得以释放全部身份点数，换卡附身去抓下一个未知的深层内鬼。

* **阵营博弈对抗（固化 vs 反固化）**：
  若敌方玩家在后续回合针对已固化角色投入更高阶的真实物证（`EVENT_HARD_COUNTER_PROOF`）或改变外部物理前置条件（如直接火烧连接栈道），可击穿旧固化支线并迫使对方重新排错，形成动态攻防。

### 4.4 机制四：“试炼幻境刷榜 → 终局历史切片公演”双层多人架构（Trial Illusion to Live Finale）

融合[《我的玩家都是演技派》第65章](https://ixdzs8.com/read/377684/p65.html)、[第79章](https://ixdzs8.com/read/377684/p79.html)的“试炼幻境选拔 + 终极试炼历史回溯 + 归序者远征”与[《这游戏也太真实了》](https://maliangwriter.com/library/%E8%BF%99%E6%B8%B8%E6%88%8F%E4%B9%9F%E5%A4%AA%E7%9C%9F%E5%AE%9E%E4%BA%86-24fec50c/)的“论坛情报众包 + 战役决战共斗”：

* **第一层：日间【试炼幻境】（海量玩家众包排雷与刷榜）**

  * **低成本平行副本**：白天数以百计的同阵营玩家进入基于当前主线状态克隆出的“试炼幻境”（仅唤醒局部 2–3 个舞台角色，单次试算 3–5 秒）。

  * **分段式情报众包**：参考[《演技派》第65章](https://ixdzs8.com/read/377684/p65.html)（楚歌发帖共享戏词线索、霍云英盯梢排除高择、夏若凌蹲守刺客爆出城防图）与[《太真实》](https://www.qidian.com/book/1029391348/)的玩家论坛生态，单名玩家每天的免费试算配额有限（如 3 次），但同阵营玩家可在【军情议事厅】共享已排除的“原生怂货名单”与触发【记忆碎片】的坐标条件。

  * **三维试炼评分**：每次幻境试算按 **历史/阵营目标还原度（40%）+ 角色扮演契合度 `1 - ooc_ratio`（35%）+ 破局消耗效率（25%）** 实时刷新单角色试炼榜。

* **第二层：夜间【主线切片合龙】与 Day 5【终局远征公演】（Top 1 入局决战）**

  * **各角色 Top 1 晋级代表制**：每晚 02:00 结算时，每个角色试炼榜排名第一的玩家方案（或房间模式下的认领主帅/空降玩家）获得当前历史切片的**唯一正史主控权**，代表该角色进入夜间全量 BSP 深度推演。

  * **终局历史回溯演出（True History Rewind）**：当战役推进至最终决战夜（如赤壁火攻夜，对应[《演技派》第79章](https://ixdzs8.com/read/377684/p79.html)的【终极试炼：事定犹须待阖棺】），系统将 5 天内所有被纠正固化的支线、锁死的心理棘轮与因果锚点一次性串联，生成一段完整无剪辑的 **2.5D 史诗回溯播片**（全服玩家可见谁在哪个时辰埋下了致命暗棋）。

  * **百人微扰共斗（归序者远征模式）**：在终局决战高潮阶段，未能夺得核心角色 Top 1 的普通玩家可消耗门票化身为战场上的基层兵卒、火船水手或传令死士（如流星般空降局部舞台槽位），通过集体微扰（合力的局部损耗与延迟）为本阵营主帅护航或补刀。

## 5. 既有防崩坏机制与数值边界（v2.0 继承与强化）

### 5.1 玩家可调控的四大合规杠杆（蝴蝶点数 / 身份点数双预算制）

* **身份点数（Identity Points，每局上限 3 点）**：用于解锁并附身不同层级的角色卡（基层小人物 `1 点`、中层校尉/谋士 `2 点`、核心主帅 `3 点`），支持在日间试炼中换卡排错与固化支线。

* **蝴蝶点数（Butterfly Points，每回合上限 3 点）**：在已附身角色内部，用于微调四大外部合规杠杆：

  1. **信息差投喂**：决定一条真假难辨的密信、流言或账目在何时进入特定角色的视野。

  2. **短期念头权重**：不改根本价值观，只微调角色本回合的优先级（如“防备诈降” vs “急于求胜”）。

  3. **微动作指令**：在关键时间窗植入符合角色性格且不触发 OOC 的小动作（如“宴席多留某副将半刻钟”）。

  4. **客观环境微扰**：在史实合理误差内微调客观条件（如“船队顺风早到半日”）。

### 5.2 小人物毛细血管视野与三大物理上限

* **不坐牢且高参与感**：拥有主帅看不到的底层情报分流权与近距离观察权（最适合用来跟踪排雷、区分原生怂货与敌方内鬼），且选角时明示该角色的**高光时间窗**（支持 Day 2 等高光窗口中途空降接管）。

* **影响力三大物理上限（严禁一票否决权）**：

  * **时间延迟**：最多影响 `±半个时辰至半天（<= 12h）`（不可直接扣留或销毁主帅军令）。

  * **局部损耗**：最多造成 `±10%–20%（<= 20%）` 的物资/士气波动。

  * **信息噪点**：最多添油加醋或漏报 `<= 1` 个细节，不可凭空捏造完全不存在的军情。

* **收敛型冷门杠杆倍率**：小人物隐蔽性强、极难被敌方第一时间锁死，一旦在临界点撬动全局或成功揪出敌方篡改黑手，结算享受 **`2.00x–2.20x` 收敛型冷门倍率**（配合消费阻尼函数，确保小人物可逆袭冲榜但不会数值通胀碾压主帅）。

## 6. 技术架构与画面演出方案

### 6.1 25–30+ 智能体并发、Redis 断点续跑与分叉存储

* **舞台分区 + 按需唤醒（Zone-Based Wakeup）**：战场拆分为曹营大帐、曹营水寨、乌林粮仓、江东都督府、七星坛、江面芦苇荡 6 大舞台。无事件波及的角色常态休眠（`SLEEPING_NO_CALL`，零 Token 消耗），有玩家附身、固化支线触发或事件波及时按需唤醒。

* **BSP 并发流水线 + 4 步断点续跑（`nightly_scheduler_worker.py`）**：

  1. `STEP_1_AGENT_THINK`：全员并发思考 + SHA-256 静态前缀 Context Caching + 私有视野隔离。

  2. `STEP_2_STATE_RATCHET`：确定性状态机更新心理槽、OOC 违和度槽、单向棘轮与支线固化状态。

  3. `STEP_3_COUNTERFACTUAL`：强推理裁判运行 4 分支反事实死局验算（`counterfactual.py`），仅当敌方主帅 `0/4` 逃生率时授予 `1.20x` 死局闭环加成。

  4. `STEP_4_CONTRACT_EXPORT`：编译零穿帮动作原语并写入 PostgreSQL JSONB 平行分叉树（`timeline_fork_store.py`）与 Redis ZSET 排行榜。

### 6.2 2.5D 战略沙盘与“零穿帮”动作原语协议

* **视觉呈现**：采用手绘国风/水墨写实 **2.5D 等距俯视沙盘（Web React + PixiJS + Spine）**，关键碰撞弹出**半身立绘 + 表情差分**，因果锚点或支线固化达成时触发全屏朱砂印章震屏演出（`ANCHOR_LOCK`）。

* **24 小时可拖拽复盘时间轴**：客户端支持随时暂停、缩放镜头偷听角落小人物密谈、一键切换对比“主线死局 vs Day 1 分叉破局线”，并在角色卡片上实时显示 `👤真人主控 / ⚡高光空降 / 🤖AI固化托管` 状态。

## 7. MDA 框架与 v3.0 阻尼天梯结算公式

* **Mechanics（机制）**：锁定底色状态机、身份点数换卡排错、记忆碎片接触解锁、OOC 违和度警觉条、跨轮次支线固化、三道时代防线、舞台分区 BSP 唤醒、反事实 4 分支死局验算、平行分叉读档树。

* **Dynamics（动态）**：白天在试炼幻境中通过“附身试探 + 论坛众包”排除烟雾弹 NPC、固化己方防线；夜间各角色 Top 1 方案围绕模糊线索与心理棘轮展开二阶欺诈与反固化博弈。

* **Aesthetics（美学体验）**：抽丝剥茧揪出内鬼的刑侦悬疑感、在 OOC 红线边缘飙戏潜伏的刺激感、支线滚雪球固化的掌控感、大群像史诗沙盘回溯的宿命感。

* **角色榜单评分公式（v3.0 校准版）**：

  ```
  综合得分 = 基础胜率分 × 时代贴合度系数 × 扮演契合度系数(1 - OOC惩罚) × 点数阻尼效率 × 角色冷门杠杆倍率 × 死局闭环加成(1.20x) + 排错固化奖励分
  
  ```

  其中：

  * `点数阻尼效率 = 1.0 / ((1.0 + 0.35 × (消耗点数 - 1)) ^ 0.75)`

  * `角色冷门杠杆倍率`：主帅 `1.00x`、谋士 `1.25x–1.40x`、基层小人物 `2.00x–2.20x`

  * `排错固化奖励分`：首次在试炼或实战中识破敌方篡改角色并完成【支线固化】的额外加分。
