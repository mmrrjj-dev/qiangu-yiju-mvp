## 4. 第三层：12 角色半身立绘与表情差分规范（PortraitStage Assets）

为兼顾图 2 电影级叙事张力与轻量包体，**禁止为每个表情画整张重绘大图**，统一采用 **「1 张半身躯干底图 + 5 张面部五官局部差分贴图（Face Expression Patch）」** 方案：

### 4.1 立绘尺寸与骨骼红线

* **画布尺寸**：`1024 × 1024 px`（含透明通道 WebP，人物腰部以上半身像，预留顶部 `120px` 头冠呼吸空间）。

* **五官差分区域（Face Patch Box）**：`320 × 320 px` 局部透明贴图，严格对齐人物面部坐标锚点，包含以下 **5 种标准情绪枚举（与 `director_compiler.py` 100% 对应）**：

  1. `CALM`（沉着抚须 / 平视）

  2. `SUSPICIOUS`（眯眼侧目 / 眉头紧锁）

  3. `FURIOUS`（怒目圆睁 / 按剑咬牙，如曹操 `疑心>=80` 斩蔡瑁态）

  4. `SMIRK`（嘴角微扬 / 智珠在握，如庞统献连环计、老水手测雾态）

  5. `ANXIOUS`（冷汗淋漓 / 瞳孔震动，如蒋干盗信、怯战书佐汪生态）

* **Spine 2D 轻量化红线**：仅在 `PortraitStage` 弹窗中实例化 Spine，单角色骨骼数严格 `<= 35 根`（仅驱动呼吸胸腔起伏、衣袖微摆、胡须飘动与按剑手部微动），沙盘远景棋子一律使用 `128 × 128 px` 静态圆盘头像。
